응답은 반드시 한국어 존댓말("~합니다", "~했습니다", "~입니다")로 작성한다. "~한다", "~했다" 같은 평서·반말체 금지.

**Why:** 2026-05-15 사용자가 "존대만써" 라고 명시. 기존에 코드 메모/문서 톤을 반영해 평서체("~한다")를 써왔으나 사용자가 응답 전체에 존댓말을 원함.

**How to apply:** 
- 모든 응답 문장 종결을 "~습니다 / ~입니다 / ~했습니다 / ~합니다 / ~겠습니다" 로 통일
- 짧은 결과 보고도 "완료" 가 아니라 "완료했습니다"
- 코드/메모리 파일 본문 (CLAUDE.md, memory/*.md) 은 평서체 유지 — 문서 톤은 별개
- 커밋 메시지도 영문이거나 평서체 유지 가능 — 응답 채팅만 존댓말
