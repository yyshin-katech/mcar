- 현재 ioniq5_siheung_dev 브런치에 siheung_dev의 지도, hmi 등을 ioniq5 시스템에 맞게 가져오기
- ioniq5 시스템이 sihueng 지역에서 ioniqev와 같은 경로와 미션을 수행하도록 하기위함



## 작업 내용

- dbc 파일은 CANdb_IONIQ5_AD_CAN_v8.dbc, CANdb_IONIQev_PCAN2.dbc, V_CAN_Release.dbc를 사용
- CANdb_IONIQ5_AD_CAN_v8.dbc는 제어 관련 정보
- CANdb_IONIQev_PCAN2.dbc는 현 시스템에서 제어 시스템으로 오브젝트 정보 전송해주는 CAN 정보
- V_CAN_Release.dbc는 차량 상태 데이터
- 현재 설정된 CAN 채널 그대로 유지
- siheung_dev 전체 구조랑 ioniq5_siheung_dev 전체 구조 비교해서 수정 계획 세우고 작업
- 수정되어 있는 부분은 검증 부분만 추가해서 검증
- ioniq5_sihueng_dev 프로젝트는 novatel gps가 아니고 ublox gps 사용
- katri_obu 데이터 사용하던 거를 siheung_dev 브런치의 siheung_v2x를 사용하도록 함
